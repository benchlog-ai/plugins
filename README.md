# Bench Log plugins

Claude plugins from the [Bench Log](https://benchlog-ai.github.io) experiments ([@benchlog.ai](https://www.instagram.com/benchlog.ai/) on Instagram).
Each one started as a build for one person's everyday life and is shared here so you can run it yourself.

## Install

In Claude Code:

```
/plugin marketplace add benchlog-ai/plugins
/plugin install wardrobe-tracker@benchlog
```

Swap in the plugin you want:

| Plugin | Experiment | What it does |
|---|---|---|
| `wardrobe-tracker` | Exp. 001 | A wardrobe Claude remembers: pieces, outfits, color pairings, event plans and shopping gaps. |
| `larder` | Exp. 002 | Your pantry, balanced meal plans and the grocery list on one page you and Claude both edit. |
| `footprints` | Exp. 003 | A travel map of where you've been, a postcard bucket list and trip plans with tickets and packing. |
| `gourmet-trails` | Exp. 004 | A restaurant log built from your food photos, with a wishlist, recommendations and shareable lists. |

## Your data

The first time you use a plugin, Claude creates a private page for it in your own account. Everything you log lives on that page.
Nothing is sent to Bench Log.
